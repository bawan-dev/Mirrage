# Shopping List

Use this as a planning list, not a final checkout page. Prices vary by region
and availability.

## Display

- 27 inch IPS monitor with VESA mount
- HDMI or DisplayPort cable with right-angle adapter if needed
- optional monitor with higher brightness if mirror test is dim

## Mirror Material

- two-way acrylic mirror sample
- final acrylic or glass mirror panel after testing
- soft cleaning cloth
- material-safe cleaner

## Compute

- Intel N100 mini PC, or Raspberry Pi 5 for lighter budget path
- SSD storage if not included
- power adapter supplied by manufacturer
- optional VESA/mini PC mounting bracket

## Audio

- small USB speakers or compact 3.5mm speakers
- short audio/USB cable
- optional rubber isolation pads

## Microphone

- USB conference microphone or USB mic array
- USB extension cable if needed
- mounting clips or small bracket

## Frame And Mounting

- wood or frame material
- removable back panel material
- screws
- corner brackets if needed
- French cleat, VESA mount, or rated wall mounting hardware
- felt/rubber pads

## Cable Management

- cable clips
- hook-and-loop ties
- strain relief clips
- cable trunking if wall cable needs hiding
- right-angle HDMI/USB adapters if clearance is tight
- Ethernet cable
- optional USB hub

## Thermal

- vent grilles or routed vent openings
- optional quiet fan only if passive ventilation fails
- dust filter material if fans are used

## Tools

- measuring tape
- screwdriver set
- drill
- level
- stud finder or wall scanner
- clamps
- saw or access to cut service
- sandpaper
- paint or finish

## Do Not Buy Yet

Delay these until basic tests pass:

- final-size glass panel
- premium display
- custom aluminium frame
- expensive microphone array
- surface transducers
- dedicated AI server
