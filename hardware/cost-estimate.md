# Cost Estimate

These are planning ranges, not fixed prices. Check current local prices before
buying anything.

## Budget Build

Uses an existing or used monitor and keeps the first frame simple.

| Category | Range |
| --- | --- |
| Display | $0-$150 |
| Mirror material | $40-$120 |
| Compute | $80-$180 |
| Audio | $10-$40 |
| Microphone | $20-$60 |
| Frame | $40-$120 |
| Cables/mounting | $30-$80 |
| Miscellaneous | $20-$60 |
| Total | $240-$810 |

Best for proving the idea, not necessarily the final look.

## Recommended Build

Uses a 27 inch monitor, Intel N100 mini PC, practical audio, and a proper frame.

| Category | Range |
| --- | --- |
| Display | $120-$280 |
| Mirror material | $100-$300 |
| Compute | $150-$300 |
| Audio | $20-$80 |
| Microphone | $40-$120 |
| Frame | $100-$250 |
| Cables/mounting | $50-$120 |
| Miscellaneous | $40-$100 |
| Total | $620-$1,550 |

This is the best target for Mirrage v1.

## Premium Build

Uses higher-quality mirror material, better display, more finished frame, and
better audio/microphone hardware.

| Category | Range |
| --- | --- |
| Display | $250-$700 |
| Mirror material | $250-$700 |
| Compute | $300-$600 |
| Audio | $80-$250 |
| Microphone | $120-$300 |
| Frame | $250-$700 |
| Cables/mounting | $100-$250 |
| Miscellaneous | $100-$250 |
| Total | $1,450-$3,750 |

Do not start here. Use premium parts only after the recommended build path is
proven.

## Cost Notes

- Glass shipping can change the total a lot.
- Used monitors can lower the budget build cost.
- Custom frame work can become the most expensive line item.
- A dedicated AI server is not included because it is future infrastructure, not
  required for the first mirror.
