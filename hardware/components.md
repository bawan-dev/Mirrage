# Components

This is the hardware component tracker for Mirrage.

Nothing here means the part is final. This is just where I keep track of what I already have, what needs testing, and what can wait.

## Already Have / Can Use Now

- Computer that can run the frontend and backend
- Normal monitor for the first display test
- Power cable for the monitor
- HDMI or USB-C display cable
- Keyboard and mouse for setup
- Wi-Fi or Ethernet connection

This is enough to test the dashboard on a screen before buying mirror parts.

## Need For First Mirror Test

- Two-way mirror material sample
- Tape or temporary clips to hold the material in front of the screen
- Dark room or dim room test
- Measuring tape
- Basic way to check frame depth

The first test is not about building the frame. It is about seeing if the screen is readable through the mirror material.

## Maybe Needed Soon

- USB microphone
- Small speaker
- Longer HDMI or USB-C cable
- Cable clips or ties
- Surge protector / power strip
- Simple temporary frame material

These can wait until the screen and mirror material test looks good.

## Later Parts

- Better display or thinner display
- Proper two-way glass or acrylic
- Mini PC or Raspberry Pi
- Microphone array
- Internal speakers
- Wall mount hardware
- Finished frame material
- Optional LED strip
- Optional temperature sensor
- Optional motion sensor

These should not be bought until the first prototype proves the basics.

## Current Buy List

Do not buy major parts yet.

Only useful early purchases:

- small mirror material sample
- cheap cable clips if needed
- maybe a USB mic if voice testing starts soon

## Notes Before Buying Anything

- Check display brightness through mirror material first.
- Measure the monitor depth including cables.
- Leave room for airflow.
- Keep power bricks outside any sealed space.
- Do not choose a final frame until the display and mirror material are tested together.
