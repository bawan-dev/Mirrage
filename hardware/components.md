# Components

This is the living component tracker for the first Mirrage physical build.

Nothing here is a final purchase decision until the visibility, heat, audio,
microphone, and software deployment tests pass.

## Already Available For Testing

- development computer that can run frontend and backend
- normal monitor for early display testing
- HDMI or USB-C display cable
- keyboard and mouse for setup
- Wi-Fi or Ethernet connection

## Needed For First Physical Tests

- two-way mirror material sample
- measuring tape
- temporary clips or tape for sample testing
- thermometer or thermal camera if available
- USB microphone for early wake/voice testing
- small wired speaker if monitor speakers are weak

## Recommended First-Build Parts

- 27 inch IPS monitor with VESA mount
- Intel N100 mini PC
- two-way acrylic or smart mirror glass after sample testing
- USB conference microphone or USB mic array
- small wired USB or 3.5mm speakers
- deep wooden frame material
- removable back panel material
- wall mounting hardware rated for final weight
- Ethernet cable if routing allows it

## Later / Optional

- premium smart mirror glass
- far-field microphone array
- better hidden stereo speakers
- quiet cooling fan if passive airflow fails
- dedicated local AI server
- motion or presence sensor
- physical brightness control

## Before Buying Final Parts

- [ ] Display is readable through selected mirror material.
- [ ] Frame depth is measured with real cables attached.
- [ ] Mini PC can run production Compose.
- [ ] Wake engine status works on target compute device.
- [ ] Heat test passes.
- [ ] Wall mounting method is chosen for the actual wall type.
