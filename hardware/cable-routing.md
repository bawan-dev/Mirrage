# Cable Routing

Cable routing should be planned before the frame is built. A clean front view is
not enough if the back is impossible to service.

## Required Cables

- display power
- mini PC power
- HDMI or DisplayPort
- USB microphone
- speaker cable or USB speaker cable
- Ethernet, recommended where possible
- optional USB hub
- optional keyboard/mouse during setup

## Recommendations

- Use Ethernet for production reliability when cable routing allows it.
- Keep Wi-Fi as acceptable but less ideal.
- Add strain relief where cables exit the frame.
- Leave a service loop so the mirror can be moved without ripping cables out.
- Use cable clips only after the final cable path is tested.
- Keep cables away from hot display areas.
- Keep power and signal cables tidy but not crushed.
- Make sure every connector can be unplugged during maintenance.

## Cable Exit

Preferred paths:

- bottom rear exit into wall trunking
- side rear exit hidden by frame depth
- down to a small cable channel

Avoid:

- cables pinched between frame and wall
- tight bends at HDMI/DisplayPort ports
- power strips hanging loose
- no access to the main plug

## Ethernet

Ethernet is recommended for the first installed mirror if practical.

Benefits:

- more reliable than Wi-Fi
- better for Docker updates
- better for Home Assistant
- better for future local AI server calls

Wi-Fi is acceptable for early testing and rooms where cable routing is not
possible.
