# Demo Script

This is a short script for a 2 minute Mirrage v1 walkthrough.

## Setup

```powershell
cd frontend
$env:VITE_MIRROR_MODE="true"
$env:VITE_MIRRAGE_DEMO_MODE="true"
npm run dev
```

Open:

```text
http://127.0.0.1:5173
```

## Script

Start on Mirror Mode home:

```text
This is Mirrage, a privacy-first ambient AI mirror platform. The home screen is
intentionally quiet: time, date, weather, assistant presence, and one small daily
nudge.
```

Open Assistant:

```text
The assistant view is voice-first. The UI has explicit states for idle,
listening, processing, speaking, returning, sleeping, and error. Push-to-talk and
browser speech output work today, while local wake-word hardware validation is
the next physical step.
```

Open Context:

```text
Daily briefing is generated by the backend from weather, Calendar, and local
memory. The deterministic context path does not automatically send personal
memory to a cloud model.
```

Open Smart Home:

```text
Smart home control is behind a backend safety boundary. Mirrage supports safe
Home Assistant domains first, such as lights, switches, scenes, and sensors.
```

Close back to home:

```text
v1 is the first complete software release: full-stack foundation, polished mirror
experience, explicit demo mode, production deployment docs, and physical build
planning. The real hardware build and wake-word microphone validation still need
target-device testing.
```

## Do Not Claim

- do not claim the physical mirror is assembled unless it is
- do not claim hands-free wake word is proven without the real model and mic
- do not claim live Spotify, Calendar, Home Assistant, or AI providers are
  connected unless they are configured during the demo
